# 🤖 Api-configg — Telegram Referral & Auto-Config Bot

ربات اختصاصی تلگرام برای جذب ممبر کانال [@APICONFIGG](https://t.me/APICONFIGG) و صدور آنی کانفیگ‌های اختصاصی ۱۰ گیگابایتی از طریق وب‌سرویس مستقیم اسپایدر پنل (SpiderPanel).

---

## 🌟 ویژگی‌ها (Features)

- **قفل عضویت اجباری (Force-Join):** کاربر تا زمانی که در کانال عضو نشود اجازه دریافت لینک دعوت و کانفیگ ندارد.
- **سیستم رفرال هوشمند (Referral System):** به ازای هر ۵ دعوت موفق یک کانفیگ ۱۰ گیگابایتی ۳۰ روزه اختصاصی تولید و اهدا می‌شود (ادوار بعدی: ۱۰، ۱۵، ۲۰ و...).
- **صدور آنی و زنده (Live Generation):** اتصال مستقیم به اندپوینت `POST /api/users` اسپایدر پنل و تولید UUID و کانفیگ اختصاصی بدون دخالت دستی.
- **کپی تک‌ضرب (One-Click Copy):** تحویل کانفیگ داخل کادر کد تلگرام (`Code block`) با تگ اختصاصی `⚡️「 Api-configg-Reward 」🎁`.
- **مدیریت مستقیم از داخل تلگرام:**
  - دستور `/vip [حجم] [روز]` : 👑 ساخت و دریافت آنی کانفیگ ویژه VIP با تگ `⚡️「 Api-config-VIP 」👑` مخصوص ادمین.
  - دستور `/panel` : مشاهده وضعیت سلامت و اتصال پنل اسپایدر.
  - دستور `/setpanel <url> <api_key>` : اتصال یا تغییر پنل و کلید در ۱ ثانیه با تست خودکار اتصال.
  - دستور `/stats` یا `/admin` : آمار لحظه‌ای کل اعضا، دعوت‌ها و کانفیگ‌های اهدا شده.

## 🚀 راهنمای استقرار روی ریل‌وی (Deploy on Railway)

این بات با زبان پایتون خالص (بدون وابستگی به پکیج‌های خارجی) و یک داکرفایل فوق سبک ساخته شده و با یک کلیک روی پلتفرم **Railway** مستقر می‌شود:

1. در داشبورد [Railway.app](https://railway.app)، دکمه‌ی **+ New** را بزنید.
2. گزینه **GitHub Repo** را انتخاب کرده و مخزن `Api-configg` را انتخاب کنید.
3. در تب **Variables** متغیرهای زیر را تنظیم کنید:

| Variable | Description | Default |
| :--- | :--- | :--- |
| `BOT_TOKEN` | توکن ربات تلگرام از BotFather | الزامی |
| `ADMIN_USER_ID` | شناسه عددی تلگرام ادمین | `5765828495` |
| `CHANNEL_ID` | شناسه عددی کانال | `-1003924644142` |
| `CHANNEL_USERNAME` | آیدی کانال | `@APICONFIGG` |
| `PANEL_API_URL` | آدرس پنل اسپایدر در ریل‌وی | `https://your-domain.up.railway.app` |
| `PANEL_API_KEY` | کلید دسترسی API پنل | `spdr_your_api_key_here` |

4. دکمه **Deploy** را بزنید. ربات به عنوان یک سرویس همیشه‌روشن (Worker) در چند ثانیه فعال می‌شود.
